# Contributing Guidelines

This repository is used for **authorized, task-based outsourced development only**.
It is not an open-source collaboration project.

本 Repository 僅用於 **經授權之任務型委外開發**，  
並非開源協作專案。

## Authorization Requirement

This repository does **NOT** accept unsolicited contributions.

Only contributors **explicitly authorized by the repository owner** may submit pull requests.

Pull requests submitted without prior authorization will be closed without review.

本 Repository **不接受任何未經授權的貢獻**。

僅限於 **經 Repository Owner 明確授權**，方可提交 Pull Request。

任何未經事前授權的 Pull Request，將在不另行說明的情況下關閉，且不進行審查。
